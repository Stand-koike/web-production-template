# Animation System

## Purpose

サイト全体の動きを統一する。

## Philosophy

アニメーションは注目を集めるためではなく、
ユーザーの理解を助けるために使用する。


## Standard Animation


### Fade Up

用途:

- Section
- Card
- Text


設定:

Y:
40px

Duration:
0.8s


### Fade In

用途:

- Image
- Background


Duration:
1s


## Rule

1画面に過剰なAnimationを入れない。

重要度:

Hero
↓
Section
↓
CTA

の順で適用する。
