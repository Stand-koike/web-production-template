# Agent Flow

## Overview

この制作システムでは、
役割ごとにAI Agentを分離する。

## Flow

Pencil.dev
↓
Builder
↓
Animation
↓
Reviewer
↓
Performance
↓
Deploy


## Agent Responsibility

### Builder

目的:
コード整理

担当:
HTML
Tailwind
構造


### Animation

目的:
体験向上

担当:
GSAP
Scroll Animation


### Reviewer

目的:
品質確認

担当:
問題発見


### Performance

目的:
高速化

担当:
画像
CSS
JS
