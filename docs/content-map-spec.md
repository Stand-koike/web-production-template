# Content Map Spec（編集用 MD → Agent 反映）

非エンジニアが表や仕様を編集し、Agent がコードへ反映するときの雛形。
**案件の中身（宿名・写真パス・コピー）は書かない。** 案件リポジトリ側でコピーして埋める。

関連パターン:

- アニメ数値 → [animation-spec.md](./animation-spec.md) → `animation.js` の `MOTION`
- 写真紐づけ・セクション対応表 → 本ファイルのコピー
- その他マッピング → 同型の MD + 依頼文

---

## 使い方

1. 本ファイルを案件リポの `docs/` にコピー（例: `docs/photo-map.md`）
2. 下表を埋める（人間）
3. Agent に「依頼文テンプレ」を渡す（実装は Agent）

---

## マッピング表（雛形）

| ID | 用途 | ファイル / パス | 反映先 | 備考 |
|----|------|-----------------|--------|------|
| e.g. hero-1 | Hero 背景 | `assets/images/...` | `sections/hero.html` | |
| | | | | |

列は用途に合わせて増減してよい（例: alt / 優先度 / ON・OFF）。

## 依頼文テンプレ（Agent 向け）

```text
@docs/{この仕様書}.md の表を実装に反映してください。

条件:
- 仕様書の値以外は変えない
- レイアウト / デザイン変更なし
- 案件固有の推測でパスやコピーを足さない（表に無い行は触らない）
- 反映後、変更ファイル一覧を報告する
```

写真紐づけの例:

```text
@docs/photo-map.md の表どおりに画像パスと alt を
該当 section / content.json へ反映してください。
表に無い画像は追加しないでください。
```

アニメ仕様の例:

```text
@docs/animation-spec.md の数値を MOTION 定数へ反映してください。
HTML は触らないでください。
```

---

## 禁止

- テンプレート本体に案件の写真名・宿名入りの完成表をコミットする
- dist を直接編集して「反映した」ことにする
